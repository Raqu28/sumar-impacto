# Sumar Impacto

Sumar Impacto es una plataforma web para gestionar donaciones comunitarias y conectar a donantes con proyectos sociales, educativos o de impacto. La aplicación permite visualizar proyectos activos, registrar donaciones y administrar la información de personas, proyectos y donaciones en una base de datos local en formato JSON.

## Descripción del proyecto

Este proyecto fue desarrollado como una aplicación de gestión sencilla con Node.js y Express, utilizando Pug como motor de plantillas para la interfaz web. La idea principal es facilitar la organización de campañas de donación y llevar un seguimiento del monto recaudado por cada proyecto.

La aplicación combina:

- una vista pública para usuarios
- una estructura modular de rutas y controladores
- manejo de datos con archivos JSON
- un flujo de donación desde la interfaz web

## Funcionalidades

- Visualización de proyectos activos
- Registro de nuevas donaciones
- Asociación de una persona donante con un proyecto
- Actualización del monto recaudado por proyecto
- Interfaz web con páginas dinámicas
- API REST para manejo de entidades principales

## Tecnologías utilizadas

- Node.js
- Express.js
- Pug
- JavaScript
- JSON como almacenamiento de datos
- dotenv para variables de entorno
